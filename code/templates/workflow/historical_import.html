Étape 1 — Préparer les fichiers

Téléchargez le modèle Excel historique, remplissez-le avec les métadonnées de vos recommandations clôturées. Préparez ensuite un fichier ZIP contenant les preuves numérisées (optionnel).

Colonnes obligatoires

Référence · Source · Criticité · Description · Date cible originale · Date de clôture · Date de création

Preuves ZIP (optionnel) — méthode recommandée

Créez un dossier par référence, déposez les fichiers dedans, zippez tout :

preuves.zip
├── RECO-2022-001/
│   ├── rapport-audit.pdf  ← noms libres
│   └── pv-recette.pdf
└── RECO-2022-002/
    └── contrat.docx

Alternative : nommer les fichiers RECO-2022-001_rapport.pdf à la racine du ZIP.

Limites

Maximum 500 recommandations · 10 Mo par fichier de preuve · 100 Mo ZIP total
